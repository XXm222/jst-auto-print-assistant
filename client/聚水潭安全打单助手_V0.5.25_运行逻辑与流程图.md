# 聚水潭安全打单助手 V0.5.25 运行逻辑

本版合入 2026-09-03 的专用浏览器及打印凭据恢复修复，并修复 Confirmed 卡单、CDP 总超时、提交前状态边界和页面恢复清理。Windows 成品尚未构建验收。

流程：领取同类订单（最多 10 单）→ 精确双号与租约回读 → 改快递/取号准备 → 提交前复核并持久化 RUNNING → 单次提交 → 后台只读确认 → 打印准备与模板检查 → 提交前复核并持久化 RUNNING/PRINT_COMMIT → 单次打印 → 回读与 PRINT_OK → SKU 幂等记录 → 完成租约，停在预发货前。

RUNNING 任务只读恢复，不重放动作。Confirmed 任务按是否已提交分别释放或转为动作待人工核对。网络和只读页面错误有退避或有界恢复；未知状态、身份冲突及打印证据不完整继续暂停。实际纸张类型仍由操作员选择并确认。

浏览器使用专用持久化 Profile，首次登录一次后保留登录；无需每次开启远程调试设置。恢复页面时仍只使用该浏览器会话。

完整审计与验证结果见 outputs/system_stability_audit_20260907/系统稳定性检查报告.md。
